# Go Projects 🚀

This repository contains a collection of Go (Golang) projects focused on backend development, distributed systems, and event-driven architecture.

---

## 📂 Projects

### 🔹 go-ajax-crud

Full-stack CRUD application using Go backend with AJAX frontend requests.

Features:

REST API with Go
AJAX-based frontend interactions
Create, Read, Update, Delete operations
Simple UI integration

➡️ Web development + API integration project.


### 🔹 go-kafka-project

Basic implementation of Apache Kafka using Go.

**Features:**

* Kafka producer
* Kafka consumer
* JSON event messaging

➡️ Located in: `go-kafka-project/`

---

### 🔹 go-kafka-microservices

Advanced event-driven microservices architecture using Go and Apache Kafka.

**Features:**

* Multiple services (producer, consumer, analytics)
* Dockerized environment
* Real-time event streaming
* Scalable microservices design

➡️ Located in: `go-kafka-microservices/`

---

## 🛠️ Tech Stack

* Go (Golang)
* Apache Kafka
* Docker & Docker Compose

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/go-projects.git
cd go-projects
```

Run any project:

```bash
cd go-kafka-microservices
docker compose up --build
```
